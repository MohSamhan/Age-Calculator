# Age Calculator

A responsive age calculator web application built using HTML, CSS, and JavaScript.

## Features

- Calculate age from date of birth
- Display age in years, months, and days
- Responsive user interface
- Date validation
- Clean and simple design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
